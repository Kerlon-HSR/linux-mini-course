🐬 Site servido por um container Docker

Esta página não está rodando direto na máquina — ela sai de dentro de um container com o nginx isolado em Alpine Linux.

nginx:alpine

imagem base (~20 MB)

:80

porta dentro do container

8080 → 80

mapeamento de portas

Como verificar que é um container de verdade:

# lista os containers em execução
docker ps

# "bate" no site de dentro do terminal
curl http://localhost:8080

# enxerga o processo de dentro do container
docker exec linux-course-app ps
